## LLM Agent in a 2D Matrix World

### v0.0.26143.1

### Observation
As we can see here the agent can move and navigate around the 2D matrix wrold however, the agent memory (conversation context) has not been preserved hence it does not remember what it has done. The agent is like a dementia patient right now LOL. And the agent is not intelligent and concious about the sorroundings around it; for eg. when I asked it to `move to the bottom of the map` in  my first prompt it tried it's best as we can see it made an `moveUntilEdgeOrWallWithoutFallingFromEdge` function call which is designed for such kind of tasks to prevent it from going out of the 10x10 constraints of the board (world). However, it only called it once and just straight forward called the function once and passed the parameter `down`; in a perfect world we would expect it to be aware of the sorroundings and distinguish obstacles and avoid them and make all necessary moves it requires to achieve the user demand. Another thing to consider here is the agent just has limited sets of tools and due to which it could not possibly achieve this goal - it only have tools such as `moveUntilEdgeOrWallWithoutFallingFromEdge` and `moveAgent` which is designed to take only a step at a time, only if the agent has a tool like `"moveAgentNSteps"` or `"moveNStepsUntilEdgeOrWallWithoutFallingFromEdge"` then it might have tried to call these functions. But still it will not be aware of its sorrounding in order to make a planned strategic moves.

### Improvements for Agent
* More sophisticated Instructios which are clear and concise stating the ability and goal of agent.
* A tool (function call) to move N times.
* An ability to scan the World - basically map the sorroundings and be aware.
* Optimisation in agentic loop for navigation and planing move suggestions to reach goals. Eg.: "go to the bottom left corner" shoud make the agent plan and create a move suggestions and execute it seamlessely and reach the goal avoiding obstacled (walls, falling off edge).
